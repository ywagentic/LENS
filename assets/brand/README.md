# LENS identity assets

The LENS symbol uses a green open circle and a central viewpoint.

- `lens-mark.svg`: website navigation mark.
- `favicon.svg`: browser icon.
- `apple-touch-icon.png`: home-screen icon.
- `lens-youtube-avatar.png`: square channel avatar.

These are LENS brand assets. Their inclusion in this repository does not imply permission to represent another project as LENS.
